# 操作マニュアル

画面の操作を、画面写真を付けて手順ごとに説明します。写真の赤枠と番号は、手順の番号に対応しています。
ページは、主に操作する人の役割ごとに分けています。

## 共通

| ページ | 内容 |
|---|---|
| [ログイン](login.md) | ログインIDとパスワードでログインする |
| [ホーム・掲示板](home.md) | ホームの見方と編集、掲示板への投稿 |
| [患者検索とカルテを開く](patient-search.md) | 患者を探してカルテを開く |
| [カルテ画面の見方](karte.md) | カルテの画面の区画と、記録を探す操作 |
| [通知](notifications.md) | 自分あての通知を受け取って片付ける |

## 医師

| ページ | 内容 |
|---|---|
| [病名](condition.md) | 病名(プロブレム・既往歴・保険病名)を登録して直す、まとめて転帰を入れる |
| [診療記録](clinical-note.md) | SOAP で診療記録を書き、シェーマに描き込んで貼る |
| [バイタル](vital.md) | 体温・血圧などの測定値を登録して直す |
| [テンプレート](template.md) | テンプレートに記入して登録する、前回の記入を写す |
| [文書作成](document.md) | 診療情報提供書などの文書を書式に入力して作る、カルテから転記する |
| [予約](appointment.md) | 次回の診察の予約を取る、日時を変える・取り消す |
| [入院予定](admission-plan.md) | 外来の患者の入院予定を登録する |
| [アレルギー・注意](allergy-caution.md) | アレルギーと診療上の注意を登録する、患者の情報の印 |
| [オーダーセット](order-set.md) | よく出すオーダーをセットに登録し、カルテからまとめて出す |
| [代行入力とカルテ承認](proxy-countersign.md) | 医師以外の代行入力と医師の承認、研修医の記録の承認 |
| [処方オーダー](prescription.md) | カルテから処方を入力して登録し、直す・削除する |
| [注射オーダー](injection.md) | カルテから注射を入力して登録し、直す・中止する・削除する |
| [化学療法](chemotherapy.md) | レジメンを適用し、投与可否の確認・化学療法室の予約・次のクールの登録をする |
| [検体検査](lab.md) | カルテから検体検査の項目を選んで登録し、直す・削除する |
| [細菌検査](micro.md) | カルテから細菌検査を登録し、採取を記録する |
| [病理検査](patho.md) | カルテから病理検査を登録し、採取を記録する |
| [放射線検査](rad.md) | カルテから放射線検査を登録し、撮影室の予約を取る |
| [生理検査](physio.md) | カルテから生理検査を登録し、検査室の予約を取る |
| [内視鏡](endoscopy.md) | カルテから内視鏡を登録し、検査目的を JED の用語で記入する |
| [処置](treatment.md) | カルテから処置を登録する、その場で行った処置を即実施で記録する |
| [手術](surgery.md) | カルテから手術を申し込む |
