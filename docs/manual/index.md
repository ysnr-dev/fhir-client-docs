# 操作マニュアル

画面の操作を、画面写真を付けて手順ごとに説明します。写真の赤枠と番号は、手順の番号に対応しています。
ページは、主に操作する人の役割ごとに分けています。

## 共通

| ページ | 内容 |
|---|---|
| [ログイン](login.md) | ログインIDとパスワードでログインする |
| [ホーム・掲示板](home.md) | ホームの見方と編集、掲示板への投稿 |
| [患者検索とカルテを開く](patient-search.md) | 患者を探してカルテを開く |
| [カルテ画面の見方](karte.md) | カルテの画面の区画と、記録を探す操作 |
| [通知](notifications.md) | 自分あての通知を受け取って片付ける |
