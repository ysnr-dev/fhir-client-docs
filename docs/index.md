# FHIR Client Docs

電子カルテの使い方と、オーダーごとの業務の流れをまとめた資料です。

| 資料 | 内容 |
|---|---|
| [業務フロー](flows/index.md) | オーダーの登録から実施・結果の確認までを、医師・看護師・薬剤部などの部署ごとに図で示します。運用を検討するときに読みます。 |
| [操作マニュアル](manual/index.md) | 画面の操作を、画面写真を付けて手順ごとに説明します。 |
| [シーケンス図](dev/index.md) | 院内の開発者向けに、操作ごとに画面・backend・上流の FHIR サーバーの間で何が起きるかを示します。 |
| [FHIR 実装ガイド](https://ysnr-dev.github.io/fhir-ig/index.html) | 電子カルテがやり取りする FHIR リソースのプロファイルと要素の定義です(別サイト)。 |

画面写真は検証用の環境で撮ったもので、写っている患者・職員・医療機関はすべて架空です。
