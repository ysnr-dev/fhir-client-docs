# シーケンス図

<!-- scripts/sync-flows.mjs が ../fhir-client/docs/order-flows/readme.md から作る。直接編集しない。 -->

院内の開発者向けに、業務フローの操作ごとに画面・backend・上流の FHIR サーバーの間で何が起きるかを示します。運用の流れは[業務フロー](../flows/index.md)を、リソースの要素は[FHIR 実装ガイド](https://ysnr-dev.github.io/fhir-ig/index.html)を読みます。

| 業務フロー | 内容 |
|---|---|
| [処方オーダー](prescription.md) | 登録から調剤・与薬まで |
| [注射オーダー](injection.md) | 登録から払出・実施まで |
| [化学療法](chemotherapy.md) | レジメンの適用からクール登録・投与・終了まで |
| [検体検査オーダー](lab.md) | 登録から採取・到着・結果報告・結果確認まで |
| [輸血オーダー](transfusion.md) | 登録から出庫・投与・副作用の記録まで、自己血の採血 |
| [手術オーダー](surgery.md) | 申込から日程確定・術前診察・入室・実施記録・症例登録まで |
| [細菌検査オーダー](micro.md) | 登録からラベル発行・採取・到着・中間報告・最終報告・結果確認まで |
| [病理検査オーダー](patho.md) | 登録から採取・ラベル発行・病理受付・レポート・結果確認・患者説明まで |
| [放射線検査オーダー](rad.md) | 登録から予約・受付・実施・読影・結果確認まで |
| [生理検査・内視鏡・処置オーダー](physio-endoscopy-treatment.md) | 放射線検査との違い、登録から予約・受付・実施・所見レポートまで |
| [他科依頼・チーム依頼](consult-team.md) | 登録から受付・回答、回診記録・終了まで、チームあての通知 |
| [放射線治療](radiotherapy.md) | 依頼から治療処方・受付・照射予定・照射・週次レビュー・終了サマリーまで |
| [リハビリオーダー](rehab.md) | 登録から受付・次回予約・日々の実施・終了・退院での打ち切りまで |
| [透析オーダー](dialysis.md) | 透析室の準備、登録から受付・予約の展開・各回の実施・終了・中断・退院での打ち切り・医事会計まで、透析経過表・患者メモ・月間統計 |
| [栄養指導・服薬指導](guidance.md) | リハビリとの違い、登録から受付・予約・指導の記録・担当薬剤師・終了・退院での打ち切りまで |
| [食事オーダー](meal.md) | 登録から食事変更・再開・パターン食・摂取量まで、入退院と外出泊の連動、食物アレルギー、食事一覧 |
| [看護指示](nursing.md) | 登録から指示受け・頻度の予定・実施・終了・中止・退院での打ち切り、看護計画・パスから出る指示まで |
| [指導・管理料](medical-management.md) | 項目マスタの準備から算定・前回算定日と上限の警告・編集・削除・会計の送信まで |
| [クリニカルパス](clinical-pathway.md) | パス定義の作成・承認から適用・日々の評価とバリアンス・フェーズの進行・終了・中止まで、予定外の追加、日程の変更 |
| [入院から退院まで](admission-discharge.md) | 入院予定・入院実施・ベッドと病棟の移動・外出泊・退院予定・退院と各取消、入院時と退院後の文書 |
| [外来の受付から会計まで](outpatient.md) | 予約・受付・Web 問診・呼出と待合表示板・診察・一時終了・診察終了・医事送信と会計済、各取消 |
